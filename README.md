# Мира — AI-таролог в Telegram

Бот с личными раскладами на GigaChat, памятью о пользователе, оплатой через ЮKassa (СБП, ЮMoney, карты),
ежедневной картой дня и прогревом. Рядом — генераторы фирменной колоды и роликов.

## Установка на сервер (Ubuntu 22.04/24.04)

```bash
sudo apt update && sudo apt install -y python3-venv ffmpeg
sudo mkdir -p /opt/mira && sudo chown $USER /opt/mira
# скопируйте содержимое папки taro-bot в /opt/mira
cd /opt/mira
python3 -m venv venv && venv/bin/pip install -r requirements.txt
curl -k -o russian_trusted_root_ca.cer https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
cp .env.example .env && nano .env      # вставьте свои ключи здесь, не в чат
sudo cp mira.service /etc/systemd/system/ && sudo systemctl enable --now mira
journalctl -u mira -f                   # логи
```

Сертификат НУЦ Минцифры нужен для TLS-соединения с GigaChat; ссылку на него стоит сверить с инструкцией Сбера.

## Оплата

1. Зарегистрируйте магазин в ЮKassa, сначала включите тестовый магазин и вставьте его shopId/ключ в `.env`.
2. Проверьте цепочку тестовой картой ЮKassa: бесплатный расклад → «Открыть за 1 ₽» → оплата → третья карта открывается.
3. После одобрения боевого магазина замените ключи. Автопродление (`YOOKASSA_AUTOPAY=1`) включайте только когда
   ЮKassa подтвердит автоплатежи; до этого бот присылает напоминание и ссылку на продление.

## Сценарий бота

1. /start (ссылка из Direct с меткой ролика, например `t.me/<бот>?start=reel01`) → 18+ → имя → дата рождения → тема.
2. Вопрос → анимация «тасую колоду» → две карты с личным толкованием.
3. Третья карта («итог») — рубашкой вверх, пейволл «Открыть за 1 ₽ + 7 дней доступа».
4. Не оплатил: каждое утро общая карта дня по знаку; прогрев через 20 ч, 3 и 5 дней.
5. Подписка: личная карта дня в 8:00, до 5 вопросов в день, «что он чувствует», память о прошлых вопросах,
   через 4 дня — «как всё складывается?».
6. Продление: напоминание за сутки, отключение автопродления в один клик («Моя подписка»).
7. Кризисные сообщения → без расклада, совет обратиться к близким и в 112.

## Колода и ролики

```bash
python tools/make_deck.py                                  # 78 карт + рубашка в assets/cards
python tools/make_reel.py reels/01_pick3_he_thinks.json out/01.mp4 [voice.mp3]
```

Сценарии роликов лежат в `reels/*.json`: `voice_text` — текст для озвучки в ElevenLabs, `scenes` — сцены
(`hook`, `pick3`, `reveal`, `list`, `cta`) с длительностью в секундах.
